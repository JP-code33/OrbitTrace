# OrbitTrace

I have build a live 3D Satellite Tracker web application. This lets users explore various satellite and get live information about them. 

# Features

1. 3D Earth
2. Real Satellite Positions using satellite.js
3. Search Feature
4. Select Satellites
5. Selected satellite getting highlighted and bigger
6. Smooth camera zoom
7. Predicted and completed orbital path
8. Ground Track
9. Satellite position replay
10. Satellite information panel
12. custom earth texture

# Built With

1. HTML
2. CSS
3. JavaScript
4. Three.js
5. Satellite.js
6. CelesTrak
7. Vite

# How It Works 

So I have seen many globe projects on Stardance, in fact I also started making one but wasn't able to finish and had to delete the project. But then I made a new project after my flight tracker and that was for a satellite tracker. I am using CelesTrak's API to get satellite's live data. You can search up a satellite or click on the markers on the globe. There is a ground track feature which lets the user know how the satellite is traveling relative to Earth and there is a replay feature.
